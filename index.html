More than a hand gesture.

Communication includes movement, expression and context. A useful translation system should consider them together.

01 / INPUT

Visual signing

Use a camera as the input for a future sign-recognition model, with a clear preview for the person signing.

02 / CONTEXT

Expression matters

Facial expressions and body movement can change meaning and should be included in model design and evaluation.

03 / OUTPUT

Text and voice

Present recognised phrases as readable text and provide optional speech output for conversations.

How it works.

A straightforward flow from visual input to a response someone can read or hear.

01 — Capture

The camera captures signing, hand movement and relevant facial cues with the user's permission.

02 — Interpret

A sign-language model analyses the video and predicts a phrase. The model must be integrated separately.

03 — Communicate

The predicted phrase appears as text and can be read aloud using the browser's speech feature.
